# DHH loading animation

Rendered from the existing game assets by `web/tools/export_loading_hero.py`
using `BattleRenderer.hero`, including the native leg cycle, carried gun and
standing weapon pose. No new artwork or altered anatomy. Thirty run samples
and one ready stance, each 128 × 112, in a horizontal transparent sheet.
Original artwork provenance: `assets/dhh-run-carry-v3.md`,
`assets/dhh-run-legs.md`, and `assets/character-prompts.json`.
