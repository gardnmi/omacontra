# Containment membrane atlas

AI-assisted original game art, generated with the imagegen skill for Omacontra.
File: finale-shield-membrane.png, 1254 × 1254, 2 × 2 cells of 627 × 627.
Top left: intact. Top right: fractured. Bottom left: collapsing.
Bottom right: contact flare. Black/transparent regions use additive blending.

Replaces the rejected vector hex shield. Cairo uses the existing sprite cache;
no per-frame image generation. Health blends intact to fractured at 55%, then
collapsing at 15%, then fades out. Only phase one displays the shield.
